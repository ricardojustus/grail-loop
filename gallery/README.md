# Gallery

Ran a grail run? PR three things into this folder, under `gallery/<your-run-name>/`:

1. Your run's `FINAL_REPORT.md` (the persistent-deficiency map is the interesting part).
2. Three captures: first cycle, last cycle, one master reference side-by-side.
3. One line in this file linking your folder, with the domain and the model used.

Reference images from the run's `refs/` folder stay out of PRs: they are third-party copyrighted material and never ship. Your own captures of your own output are yours to share.
